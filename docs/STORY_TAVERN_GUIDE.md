# 故事酒馆 1.0.1 使用说明

## 安装和更新

安卓：把`StoryTavern-1.0.1.apk`复制到手机，点击安装。已经安装1.0.0时直接覆盖安装，沿用应用签名，不需要卸载。安装完成后打开“故事酒馆”。应用独立运行，不要求电脑开机；阅读、导入和编辑设定可以离线，生成故事与AI整理需要联网。

电脑：运行`StoryTavern-1.0.1-Setup.exe`，选择安装目录；也可以使用`win-unpacked/StoryTavern.exe`。数据保存在当前Windows用户的`%APPDATA%/StoryTavern`目录。两种启动方式使用相同数据目录，原版Chatbox和SillyTavern使用各自的数据。

更新前可以先导出一份完整备份。若手机提示签名冲突或安装失败，保留原应用和数据，记录报错再排查。

## 首次连接模型

进入“故事工作台 → 接口”，点“导入自己的接口配置”，选择你自己的接口配置 JSON 文件。密钥保存到当前设备。也可以直接填写接口地址和密钥。

新故事默认使用Gemini 3.8 Flash；可以选DeepSeek V4 Pro或其他内置模型，再点“保存接口设置”或“保存并测试连接”。已有对话使用输入框旁的模型选择器切换模型。

内置模型预设需根据实际服务的可用模型调整。字数设置是写作目标，约3000字的故事回复可能需要等待一段时间；以正文是否继续出现为准。

私人接口配置和勾选了“包含接口密钥”的备份都含认证资料，只用于自己的设备间传递。普通安装包和源码包不含私人接口密钥。

## 接着已有故事玩

1. 在“接着旧故事”选择TXT或HTML。
2. 预览中检查每条消息是“我的指令”“AI正文”还是“故事设定”。有明确角色标签的记录会自动识别；纯小说正文会先作为AI正文，允许你调整。
3. 点击“确认恢复全部路线”。记录会成为真正的对话，出现在左侧对话列表中。
4. 打开对话，输入“继续”或描述接下来的剧情。AI会承接已经导入的故事。

Chatbox交互式HTML里保存的历史分支会分别恢复为独立对话。每条路线使用自己的上下文；完整原始文件也保存在本地素材资料中，随完整备份一起迁移。

普通TXT/HTML没有角色标签时，软件无法凭空准确推断谁说了哪段话，可以在预览中改角色、修改正文、按空行拆分。HTML脚本不会在导入过程中执行。

导入后，可进入该对话的“故事设定 → 本故事”为它添加世界和人物。原文历史已经可以作为故事基底，不强制另填设定。

## 新建世界、角色和故事

在“世界 → 新建世界”给世界命名，把自然语言、Markdown或JSON等原文粘贴进大文本框，点击保存。角色同样通过“角色 → 新建角色”粘贴设定；每个角色可以单独设置默认回复字数、开场白和示例对话。

默认直接使用原文。“AI整理”是可选操作：先生成预览，只有点击采用才替换编辑框内容；采用后仍需保存。首次原文与导入资料会保留。

PNG/JSON角色卡和JSON世界书可以直接导入。常见角色信息、开场白、示例对话和世界书触发条目会转换为可编辑的简单界面；专属于其他酒馆插件的扩展脚本不会自动执行。

“新建故事”可以选多个世界与人物，提前设定每次回复的字数、视角和文风，再填写开场。

- 故事叙述者：你给剧情简介、行动或性格修正，AI展开成小说正文。默认目标约3000字。
- 角色扮演：AI扮演主要角色，使用它的默认回复长度。选取多个角色时，第一个是主要角色。

一个故事会保存当时选中的世界和人物副本。之后修改素材库，不会自动改变已经开始的故事；要修改正在玩的故事，进入它自己的“故事设定 → 本故事”。

## 对话、阅读和剧情分支

点击聊天上方“对话 / 阅读”随时切换。对话模式保留Chatbox的消息交流方式；阅读模式连续显示正文，把你的指令折叠起来，需要时展开。

每条消息都可以编辑。打开编辑后选择：

- “保存到原对话”：在当前路线修改这条记录；后面的记录保留，之后的自动记忆会重新整理。
- “另存为新对话”：复制修改位置之前的故事，并把修改后的消息作为新路线的起点。原路线保持原样，后续旧剧情不会进入新分支。

无需先修改时，也可以点击“从这里开分支”。新路线会出现在对话列表里，可以输入新的后续指令。旧路线始终可以从列表打开，便于比较和回到原剧情。

## 玩法工具、角色参与与记忆

“剧情工具与记忆”按需展开，平时主要显示正文。工具包括继续故事、探索、随机事件和人物互动；也可以直接在输入框用自然语言提出玩法要求。

“我的参与方式”默认导演，也可以改成角色，选择故事中的一个人物或填写自己的姓名和设定。它决定你如何参与；AI的叙述者/角色扮演模式在“本故事”中单独设置。

每个故事可以选择：

- 自动记忆：每6次完整AI回复后整理剧情与人物关系；需要时也能手动整理。
- 手动记忆：只在你点击“现在整理剧情与人物关系”时调用模型。

长历史会按顺序分段整理，可能产生多次模型调用。手动编辑现有记忆，或新增“手动记录 / 固定事实”，可以纠正漏记和固定人物资料。正在整理时修改正文或记忆，软件会丢弃旧整理结果，避免覆盖你的修改。

分支只使用分支点之前的记忆。自动整理失败不会删除已经保存的故事，界面会显示状态，之后可以重试。

## 手机和电脑互相迁移

进入“备份 → 导出完整备份”，选择保存位置。备份包括对话、分支、世界、角色、记忆、原始导入文件和对话引用的本地附件。默认不包含接口密钥；需要只在自己的设备之间迁移接口认证时再勾选。

把备份JSON复制到另一台设备，选择“导入完整备份”。导入始终新增副本，不覆盖已有对话。双方分别修改过同一段故事时，两份都会保留。

接口地址冲突时新增接口副本，导入的对话使用对应接口；同地址配置会补齐模型列表，保留当前设备已填写的密钥。旧版1.0.0的完整备份仍可导入。

只需要阅读或分享故事时，可在剧情工具里选择“导出正文”或“导出完整对话TXT”。后者保留角色标签，方便再次导入。

## 已知边界

本仓库提供源码。请按 README 自行构建并在目标设备验证，安装与签名资料不随源码提供。

当前没有自动云同步、专属其他酒馆插件的脚本执行或精确字数保证。模型可能记错剧情，可以编辑记忆和固定事实纠正。来自接口的错误或额度问题需要根据实际提示处理。
